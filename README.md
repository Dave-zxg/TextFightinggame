# TextFightinggame 文字格斗游戏

一款纯 Java 编写的控制台文字格斗游戏：注册登录后创建自己的角色，与随机出现的敌人进行回合制战斗，不断连胜来挑战更强的对手。

## 功能特性

- **账号系统**：注册 / 登录 / 退出，内存存储用户数据
  - 注册校验：用户名 3~16 位（字母 + 数字，不能纯数字）、密码 3~8 位（字母 + 数字组合），均要求用户名唯一
  - 登录校验：随机验证码 + 密码验证，密码连续错 3 次账号锁定
- **角色创建**：共 20 点自由属性点，可分配到生命值（每点 +10 HP）、攻击力（每点 +2 ATK）、防御力（每点 +1 DEF）
- **回合制战斗**：双方交替行动，带 ASCII 血条实时显示
- **玩家技能**：
  | 技能 | 效果 | 消耗 |
  | --- | --- | --- |
  | 普通攻击 | 造成 `ATK - DEF` 伤害（至少 1 点） | 无 |
  | 强力一击 | 造成 1.8 倍攻击力的伤害 | 10 HP |
  | 生命汲取 | 恢复 0~20 点生命 | 10 HP |
- **四种敌人**（每场随机抽取），各带专属技能：
  | 敌人 | HP | ATK | DEF | 技能 |
  | --- | --- | --- | --- | --- |
  | 初级战士 | 80 | 15 | 10 | 猛击（1.5 倍伤害） |
  | 敏捷刺客 | 60 | 20 | 5 | 快速攻击（2 次 0.5 倍伤害） |
  | 重装坦克 | 120 | 10 | 20 | 防御姿态（下次受伤减半） |
  | 神秘法师 | 70 | 25 | 8 | 火球术（1.8 倍伤害） |
- **成长机制**：
  - 每场战斗胜利后恢复 20~40 点生命值
  - 每连胜一场，所有敌人属性提升：HP +10、ATK +3、DEF +2
  - 每累计 3 胜，玩家属性提升：最大生命 +30、攻击 +5、防御 +3

## 运行环境

- JDK 14 及以上（使用了 switch 箭头语法），推荐 JDK 17 / 21 / 25 LTS
- 无需任何第三方依赖

## 运行方式

### 方式一：IntelliJ IDEA（推荐）

1. 用 IDEA 打开项目根目录
2. 运行 `src/APP.java` 的 `main` 方法即可开始游戏

### 方式二：命令行

```bash
# 编译（-encoding UTF-8 保证中文正常编译）
javac -encoding UTF-8 -d out src/APP.java src/domain/*.java src/ui/*.java

# 运行
java -cp out APP
```

Windows PowerShell / CMD 可将路径分隔符换成 `\`，命令相同。

> **提示**：若在 Git Bash / Windows Terminal（UTF-8 环境）下中文显示乱码，可先执行 `chcp 65001` 切换到 UTF-8 代码页再运行，或直接在 CMD / IDEA 中运行。

## 游戏流程

```
启动 → 登录/注册 → 创建角色（分配 20 属性点）
     → 随机遭遇敌人 → 回合制战斗（至一方倒下）
     → 胜利：恢复生命 + 胜场 +1（可选择继续，敌人会更强）
     → 失败：游戏结束，结算总胜场
```

## 项目结构

```
├── src/
│   ├── APP.java                  # 程序入口
│   ├── domain/                   # 领域模型
│   │   ├── Character.java        # 角色基类（属性、受伤、治疗、存活判定）
│   │   ├── HeroCharacter.java    # 玩家角色（技能列表）
│   │   ├── EnemyCharacter.java   # 敌人角色（专属技能、防御减伤）
│   │   └── User.java             # 用户账号（id、用户名、密码、状态）
│   └── ui/                       # 界面与流程
│       ├── Login.java            # 登录 / 注册 / 验证码
│       └── FightingGame.java     # 创建角色、战斗循环、伤害计算
└── README.md
```
